PIZZLING APK তৈরি
১) এই ZIP-এর ভেতরের সব ফাইল GitHub Repository-র মূল জায়গায় আপলোড করুন; .github ফোল্ডারটিও দিতে হবে।
২) Repository > Actions > Build PIZZLING APK > Run workflow চাপুন।
৩) Build সফল হলে Run-এর Artifacts থেকে PIZZLING-APK ডাউনলোড করুন।
৪) ZIP Extract করে app-debug.apk ইনস্টল করুন।

এটি Debug APK। অ্যাপের ডেটা ফোনে লোকালি থাকে; নিয়মিত JSON ব্যাকআপ রাখুন।
